# Bookstore Data Analysis Using PostgreSQL

## Project Overview
This project focuses on analysing bookstore-related data using PostgreSQL. It explores relationships between books, customers, and orders through SQL queries to extract useful information and demonstrate practical database analysis skills.

## Dataset Description
The project uses three datasets:

- **Books.csv** – Contains information about books.
- **Customers.csv** – Contains customer-related information.
- **Orders.csv** – Contains order and transaction information.

## Tools & Technologies
- **Database:** PostgreSQL
- **SQL Environment:** pgAdmin 4
- **Language:** SQL

## Project Objectives
- Explore and analyse bookstore data.
- Retrieve relevant information using SQL queries.
- Examine relationships between books, customers, and orders.
- Practise querying and analysing relational database tables.

## SQL Analysis
This project contains SQL queries executed on the three database tables to perform data retrieval, filtering, and analysis.

## How to Run the Project
1. Install PostgreSQL and open pgAdmin 4.
2. Create a database.
3. Import the Books, Customers, and Orders datasets into the database.
4. Open `sql_project.sql` in pgAdmin 4 Query Tool.
5. Execute the queries to explore the analysis.

## Key Learning Outcomes
- Practical experience working with PostgreSQL.
- Writing and executing SQL queries.
- Working with multiple relational database tables.
- Analysing structured data using SQL.
